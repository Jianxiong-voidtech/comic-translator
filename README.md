# Manga Translate Agent (MVP)

A lightweight prototype for automated manga translation and typesetting, paired with a QA/refactoring check script designed for **Devin Bot** workflows.

## Pipeline Overview
1. **Text / Bubble Box Detection**: Extracts dialogue regions (supports optional `manga-ocr` / `easyocr` or bounding-box fallback).
2. **Inpainting / Cleanup**: Masks detected text areas and fills the bubble background cleanly.
3. **LLM Translation**: Translates extracted dialogue with bubble-fit awareness (supports OpenAI-compatible API via `.env`, with a built-in mock translator when no API key is set).
4. **Auto-Typesetting & Render**: Wraps text and scales font size automatically using `Pillow` (`PIL`).
5. **Devin Bot QA (`src/devin_qa.py`)**: Audits translated lines for bubble overflow / length bloat and outputs actionable fix suggestions before PR/deployment.

## Quick Start

```bash
pip install -r requirements.txt
python run_demo.py
```

Outputs will be saved to `output/`:

* `output/sample_jp.png` - Generated sample Japanese manga panel
* `output/sample_masked.png` - Detected text bounding-box mask preview
* `output/sample_en.png` - Cleaned & typeset translated output
* `output/qa_report.json` - Quality check report generated by `devin_qa.py`
